# Lean Theorem Prover RL Project

This project explores how to build a multi-stage reinforcement learning system for interacting with the Lean proof assistant. It is currently organized into two stages:

---

## Stage 1: Lean File Repair with RL

**Objective:** Repair invalid Lean files by learning character-level editing strategies.

### Input
- Approximate formalizations of mathematical definitions or theorems, typically generated by a language model.
- These inputs may contain syntax or type errors.

### Agent
- A reinforcement learning (RL) agent that edits `.lean` files one character at a time.
- The policy takes as input the full code context and outputs an edit: which line, which character, and which replacement to make.

### Reward
- +1 for producing a syntactically and type-correct Lean file (i.e., one that successfully compiles).
- Compilation is tested using `lake build`.

### Goal
- Learn general editing strategies that increase the mathematical validity of generated code.
- The long-term aim is to enable an RL agent to refine approximate formal code into valid Lean code.

### Alternative Reward Design
- Another approach is to train a classifier to distinguish valid from invalid Lean files.
- The classifier's output (probability of validity) could be used as a differentiable reward signal for the repair agent.

---

## Stage 2: Theorem Proving with RL

**Objective:** Train an agent to prove new theorems in Lean by constructing valid proofs.

### Input
- Valid `.lean` files containing incomplete or conjectural theorems.
- These may be definitions without proofs, or theorems with `sorry` placeholders.

### Agent
- A reinforcement learning agent guided by tactic prediction or proof completion.
- The agent interacts with the Lean proof state to attempt a valid proof.

### Goal
- Extend the formal Lean library with valid new theorems, proofs, and definitions.
- Ultimately build a feedback loop from informal text → approximate formalization → corrected Lean code → provable theorems.

---

## Roadmap

- ✅ Build character-level RL environment for Lean code repair.
- ✅ Train RL policy on valid/invalid examples and compile feedback.
- ⏳ Integrate proof goal-based reward shaping.
- ⏳ Add tactic-level exploration to transition toward automated theorem proving.
- ⏳ Construct a curriculum: increasingly long files, increasingly many inserted errors.
- ⏳ Incorporate Lean's proof state API (e.g., via LeanDojo) for deeper theorem exploration.

---

## Usage

The project includes scripts to:
- Tokenize and count Lean tokens from a codebase.
- Generate valid prefixes of Lean files (for curriculum training).
- Train and evaluate RL agents for Lean file repair.
